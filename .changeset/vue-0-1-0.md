First release of `fancy-ui-vue`: the Vue 3.5 counterpart of `fancy-ui-svelte`, at parity with all 144 components, the `sound` family and the cameleon skin engine on the `fancy-ui-vue/cameleon` subpath. Every component is a faithful transpose of the Svelte reference (own-props `<Name>Props`, `v-model:<name>` for each bindable, `defineExpose({ ref })`, snippets as slots, `<style scoped>` with the same class and keyframe names); every deliberate difference is listed in the package README. Ships `styles.css`, a `tailwind.css` `@source` entry, and typed declarations checked against the `vue@3.5.2` floor.
