Landing page: the footer's synthwave scene is now a layered DOM composition instead of a canvas — CSS sky/stars/fog/scanlines, a CSS 3D perspective grid with a seamless infinite scroll, and optimized AVIF/WebP art layers (striped sun, mountains, skyline, palms, retro car) generated by a committed asset pipeline (~916 KB total, down from 22 MB of raw sources). A single GSAP timeline drives all motion, pointer parallax fans the layers by depth, and `prefers-reduced-motion` renders a fully static scene with no timeline and no listeners. The CTA text and footer columns remain plain HTML above the scene. Docs-site only — no change to the published component API.
